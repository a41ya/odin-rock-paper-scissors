# Rock Paper Scissors

A browser-based Rock Paper Scissors game built with HTML, CSS and JavaScript as part of The Odin Project.

## Preview

![Rock Paper Scissors](./images/preview.png)

## Live Demo

[Play the game](https://a41ya.github.io/odin-rock-paper-scissors/)

## Features

* Rock, Paper, Scissors
* Live score
* Round history
* First to 5 wins
* Win / lose screens
* Start a new game

## Built With

* HTML
* CSS
* JavaScript
* DOM manipulation
* DOM events
